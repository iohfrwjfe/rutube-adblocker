# Rutube AdBlocker

Блокировщик рекламы для видеохостинга Rutube.

## Возможности

- Блокировка видеорекламы (прероллы перед видео, мидроллы в середине и построллы)
- Автоматический пропуск и перемотка рекламных фрагментов в плеере
- Удаление рекламных баннеров на страницах, под плеером и в рекомендациях
- Скрытие всплывающих окон, промо-блоков подписок и навязчивых уведомлений
- Блокировка рекламных SDK, счетчиков и трекеров

## Установка

1. Откройте страницу расширений в браузере:
   - Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
2. Включите **Режим разработчика** (Developer mode).
3. Нажмите **Загрузить распакованное** (Load unpacked) и выберите папку с репозиторием.

## Юзерскрипт

Если используется Tampermonkey или Violentmonkey, можно установить скрипт `rutube_adblocker.user.js`.
